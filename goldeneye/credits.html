Emulator credits

This player loads EmulatorJS 4.2.3 from its versioned CDN. EmulatorJS is distributed under the GNU GPL v3.

The default N64 core is Mupen64Plus-Next. An alternate ParaLLEl N64 core is available with ?core=parallel. Core notices are available in the emulator information menu and upstream source repositories.

Native control integration references the GoldenEye decompilation project.

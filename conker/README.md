# Slopper's Bad Fur Day

Gameslop's browser edition: native Slopper character models, matching red hands,
and a title-screen animation that stamps Slopper's over Conker's with a matte
red hand. Keyboard, controller, touch controls, fullscreen and browser saves.

Built from the verified EU release by `tools/build-conker-public.py` in the
source workspace. This folder contains only the browser release. The input copy,
asset extraction and development QA data are kept out of the release.

See `credits.html` for runtime notices and upstream source links.

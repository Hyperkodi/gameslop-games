Your browser storage

If “Remember this file” is selected, the chosen game file is kept in IndexedDB on this device. Saved games and preferences are also stored there. No account, analytics or tracking code is used by this player. Your hosting provider may keep ordinary web request logs. “Forget game file” removes the remembered game archive; saved games remain available. Clear this site’s browser data to remove everything. Export saves first if you want a backup.

Gameslop menus and mascot hands

Slop Nukem 3D adds custom native menus and optional red mascot hands for retail game files. Artwork notes. Shareware retains its original menus and artwork.

Browser shell & Ansem artwork

Gameslop supplies the launcher, touch controls, storage integration and documentation. An optional, generated Ansem caricature replaces trooper enemies for supported retail game files.
